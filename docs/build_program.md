# Maintainer Guide: Build-Time Program Subsystem (`ti_program_t`)

> **Audience:** Maintainers and contributors managing compiler lifecycle and build-time memory in TienInterpreter.

---

## 1. Struct: `ti_program_t` (`struct TI_PROGRAM_STRUCT`)

Defined in `src/include/ti_build_program.h`:

```c
typedef struct TI_PROGRAM_STRUCT {
    ast_t       *root_ast;    /* Root AST node of the compiled program */
    alloc_hdr_t *alloc_list;  /* Dedicated allocation list tracking all build-time memory */
} ti_program_t;
```

### Purpose & Field Contribution
`ti_program_t` encapsulates the compiled AST of a script alongside an isolated intrusive allocation list (`alloc_list`). All diagnostics and syntax errors are routed directly to the global error logging subsystem (`ti_log` / `ti_log_line`).

| Field | Type | Purpose & Contribution to Module Mechanics |
| :--- | :--- | :--- |
| `root_ast` | `ast_t *` | **Root AST Node:** Points to the root compound statement node of the compiled abstract syntax tree generated by `parser_parse()`. Borrowed by the runtime visitor for execution. |
| `alloc_list` | `alloc_hdr_t *` | **Build-Time Intrusive Allocations Head:** Head pointer of the intrusive doubly-linked list (`alloc_hdr_t`) tracking every build-time allocation (tokens, identifiers, AST nodes, parser/lexer structures). |

---

## 2. Memory Lifecycle & Batch Deallocation

### `ti_program_create(void)`
- Allocates the `ti_program_t` container using `tracked_calloc(NULL, 1, sizeof(ti_program_t))`.
- Initializes `root_ast` and `alloc_list` to `NULL`.

### `ti_program_free(ti_program_t *prog)`
- Performs instantaneous $O(N)$ batch deallocation of every build-time object allocated on `prog->alloc_list` via:
  ```c
  tracked_free_all(&prog->alloc_list);
  ```
- Because AST nodes, tokens, and temporary strings are linked to `prog->alloc_list`, manual recursive freeing of individual AST nodes is not required for clean memory recovery.
- Finally frees the program container itself via `tracked_free(NULL, prog)`.
